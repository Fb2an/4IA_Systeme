# Systeme und Netze – 4IA

Dieses Repository enthält Übungen, Projekte und Aufgaben aus dem Fach **Systeme und Netze** der 4IA.

Die einzelnen Ordner enthalten Programme und praktische Beispiele zu den im Unterricht behandelten Themen. Das Repository wird im Laufe des Schuljahres laufend erweitert.

## Inhalte

Aktuell enthalten:

- `LinkedList` – Implementierung und Übungen zu verketteten Listen

Weitere Projekte und Übungen werden im Laufe des Schuljahres ergänzt.

## Verwendete Sprachen

Der Großteil der Aufgaben wird in **C** umgesetzt.
